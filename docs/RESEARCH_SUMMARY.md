# Research summary

## Цель

Проверить, существует ли спрос на удобный путь онлайн-покупки лекарств с доставкой, и какие элементы повышают доверие к сценарию рецептурных препаратов.

## Метод

- не менее трёх глубинных интервью для понимания контекста и барьеров;
- количественный опрос по онлайн-покупке лекарств;
- анализ вторичных материалов и конкурентного поля.

В доступной локальной выгрузке — **30 заполненных ответов**. В исходной презентации упоминалось 45, поэтому в публичном кейсе используется только проверяемое число 30.

## Результаты опроса

| Наблюдение | Доля |
| --- | ---: |
| Уже покупали лекарства онлайн | 100% |
| Пользовались онлайн-аптекой менее месяца назад | 50% |
| Покупали с доставкой на дом | 57% |
| Оценили опыт покупки на 5/5 | 73% |
| Считают 1–2 дня приемлемым сроком | 83% |
| Знают о возможности покупки рецептурных препаратов онлайн | 60% |
| Хотят калькулятор дозировок | 83% |
| Хотят информацию о побочных эффектах | 70% |
| Хотят видеть несовместимость препаратов | 93% |
| Хотят подсказки по приёму в комплексе | 80% |

## Выводы для продукта

1. Онлайн-покупка лекарств уже привычна для опрошенной аудитории; барьером становится доверие к рецептурному и доставочному пути.
2. Прозрачные наличие, срок доставки и статус проверки важнее «широкого» MVP.
3. Информационные подсказки востребованы, но медицинские рекомендации требуют отдельной клинической и юридической проработки; они не являются обязательной функцией MVP.

## Ограничения

Выборка небольшая и не репрезентативна для всего рынка. Результаты используются для формирования гипотез и приоритетов, а не как доказательство рыночного спроса.
