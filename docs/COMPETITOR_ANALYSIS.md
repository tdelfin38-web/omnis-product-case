# Конкурентный контекст

## Рынок учебного кейса

В исследовании рассматривались Apteka.ru, Ригла, Еаптека и «Планета здоровья». В исходных материалах упоминались доли Apteka.ru — 24,7% и Ригла — 8,5%; эти значения отражают материалы учебной работы и не должны читаться как актуальные рыночные данные.

## Альтернативы пользователя

| Альтернатива | Сильная сторона | Неразрешённая потребность для Omnis |
| --- | --- | --- |
| Офлайн-аптека | Немедленность и привычность | Нужно ехать, заранее неизвестно наличие |
| Онлайн-аптека | Каталог и доставка | Rx-путь и статусы могут быть фрагментированы |
| Звонок в аптеку | Можно уточнить детали | Ручной, долгий и непредсказуемый процесс |
| Omnis (концепт) | Один прозрачный пользовательский путь | Должен доказать юридическую и операционную состоятельность |

## Потенциальная дифференциация

Не «ещё один каталог», а единый контролируемый путь: наличие → проверка рецепта → заказ → доставка → понятные исключения. Сначала эту ценность нужно подтвердить в ограниченном пилоте и только потом масштабировать.
