# Roadmap

| Горизонт | Цель | Результат |
| --- | --- | --- |
| 0–3 месяца: discovery + MVP | Валидировать путь и операционный контур | Каталог, наличие, загрузка/проверка рецепта, заказ, статусы, ограниченный пилот |
| 4–6 месяцев: v1 | Уменьшить потери и обращения | Улучшение статусов, исключений, доставки и UX по feedback |
| 7–12 месяцев: MLP | Повысить ценность повторного сценария | Персонализация в допустимых границах, интеграции с медсервисами, расширение географии |
| 2–3 года | Масштабировать подтверждённую модель | Новые города, партнёры, маркетинг и операционные стандарты |

## Принцип приоритизации

Сначала снимаем критичные риски: юридическая допустимость, доступность препарата, надёжность проверки рецепта и доставка. Затем оптимизируем конверсию и повторное использование. Информационные и персонализированные функции берём только после подтверждения базового пути.
