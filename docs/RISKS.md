# Риски

| Риск | Почему критичен | Снижение риска |
| --- | --- | --- |
| Регулирование Rx-доставки | Сценарий может быть юридически недопустим | Юридическая экспертиза до пилота, работа только с лицензированными партнёрами |
| Ошибка проверки рецепта | Риск для пользователя и партнёра | Чёткая ответственность, аудит статусов, ручная проверка в MVP |
| Нет товара / замена | Потеря доверия в критичном сценарии | Актуальное наличие, согласованный путь замены, прозрачное уведомление |
| Задержка доставки | Пользователь может остаться без лекарства | SLA, видимые статусы, раннее уведомление и поддержка |
| Чувствительные данные | Высокие требования к защите | Минимизация данных, разграничение доступа, аудит и безопасное хранение |
| Нерепрезентативное исследование | Неверная приоритизация | Проверка гипотез на расширенной выборке и в пилоте |
